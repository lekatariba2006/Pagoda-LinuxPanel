# С помощью панели Pagoda вы можете за минуту настроить среду Linux на облачном сервере.
## Предисловие
**Pagoda Panel** - это программное обеспечение для управления серверами, поддерживающее системы Windows и Linux. Оно позволяет легко управлять серверами через Интернет и повышать эффективность эксплуатации и обслуживания. Вы также можете настроить серверную среду одним щелчком мыши (LAMP/LNMP/Tomcat/Node.js) , вы также можете создать веб-сайт управления, FTP, базу данных, иметь визуальный файловый менеджер, визуальный программный менеджер, визуализировать процессор, память, графики мониторинга трафика, планировать задачи и другие функции. В то же время, чтобы упростить пользователям создание веб-сайта, на панели Pagoda можно одним щелчком мыши развернуть подключаемый модуль для развёртывания в один клик: Discuz, Wordpress, Ecshop, Thinkphp, Z-blog, Dedecms и другие программы. Также доступна очень удобная миграция в один клик: на двух серверах установлена версия Pagoda Linux Panel 5.2, которая позволяет одним щелчком мыши перенести веб-сайт, FTP и базу данных на другой сервер. В общем, избавьте себя от лишних хлопот!

## Экологические требования
Требования к среде панели Linux
Панель Pagoda Linux поддерживает следующие системы: (CentOS, Ubuntu, Debian, Fedora); обеспечивает чистую операционную систему и не содержит таких программ, как Apache/Nginx/php/MySQL, установленных в других средах. Требования к объему памяти: не менее 128 МБ, рекомендуется 512 МБ или более, при этом на саму панель приходится около 10 МБ памяти; если вышеуказанные условия не соблюдены, установка и использование будут невозможны. Пожалуйста, проверьте перед установкой.

## Требования к среде панели Windows
Операционная система: поддержка 2003 (x86)/2008 (x64)/2012/2016. 
Требования к среде: Microsoft .NET Framework 2.0. 
Требования к памяти: минимум 1 ГБ, рекомендуется более 1 ГБ.

### Установка панели Pagoda
Используйте следующую команду, чтобы выбрать подходящий установочный скрипт для вашей системы Linux или просмотреть адрес установки скрипта на панели Pagoda Linux.

**Команда установки Centos:**
```
yum install -y wget && wget -O install.sh http://download.bt.cn/install/install.sh && sh install.sh
```
**Команда для установки Ubuntu/Deepin:**
```
wget -O install.sh http://download.bt.cn/install/install-ubuntu.sh && sudo bash install.sh
```
**Команда установки Debian:**
```
wget -O install.sh http://download.bt.cn/install/install-ubuntu.sh && bash install.sh
```
**Команда установки Fedora:**
```
wget -O install.sh http://download.bt.cn/install/install.sh && bash install.sh
```
**Замечания:**

Если в процессе установки панель Pagoda была разделена на разделы и не была подключена, диск с данными будет автоматически подключен к каталогу /www.
Если у вас новый диск, программа автоматически разделит его на разделы и отформатирует в файловую систему ext4, подключённую к каталогу /www.
Инструмент имеет один и только один раздел, который можно подключить
